# 5.3 Why This Became Physically Possible: Parallel Computation Instead of Step-by-Step

Powerful GPUs, capable of running thousands of computations at once, existed before 2017 too. The problem wasn't the hardware — it was that the RNN architecture simply couldn't make use of it: since token #5 can't be processed until token #4 is done, computation has to proceed strictly in order, no matter how many parallel cores the GPU has sitting idle. By removing the sequential dependency, the transformer turned sentence processing into a set of matrix operations that could all run at once. Only then did GPU power actually become useful for this task — GPUs didn't make transformers possible; transformers finally gave GPUs a job they were built for.
