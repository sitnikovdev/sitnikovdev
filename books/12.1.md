### 12.1 The Problem: Hand-Writing the ReAct Loop Every Time Doesn't Scale

In Chapter 9, we broke down the ReAct loop: reason → act → observe the result. Implementing it from scratch isn't too hard for one specific case — but **every new project would mean rewriting the same connective logic** all over again:

- How to assemble the prompt
- How to call the model
- What to do with its response
- How to pass that response along

If you compare this to regular development, it's like rewriting the networking layer from scratch for every new app instead of reaching for a proven library.

**LangChain exists precisely to pull that repetitive machinery out into reusable building blocks.**
