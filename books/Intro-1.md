# What changed: development before and after LLMs

Development used to follow a predictable path:

> requirement → task → code

A product manager gathered the client's requirements, turned them into a task, and the developer sat down and wrote the code. **A developer's value was measured mainly by one thing: how well they could turn a task into working code.**

Then came companies like OpenAI, and products like ChatGPT. That chain didn't just change — a new link got inserted into it.

Now, getting code doesn't require deep knowledge of a programming language. You describe what you need to the neural network, and within a few minutes — depending on how complex the task is — you get a working result.

This isn't speculation. It isn't a hypothesis about some future. **It's happening right now, every day, in real development work.**

And it's changing the essence of the profession itself:

- A developer's value used to lie in _being able to write code_
- Writing code is increasingly accessible without deep programming knowledge
- So the question "what makes a good developer" is shifting too
