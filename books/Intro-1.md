# What changed: development before and after LLMs

Development used to follow a predictable path. A product manager gathered the client's requirements, turned them into a task, and the developer sat down and wrote the code. The chain was simple: requirement → task → code. A developer's value was measured mainly by how well they could turn a task into working code.

With companies like OpenAI, and products like ChatGPT, that chain broke — or rather, a new link got inserted into it. Now, getting code doesn't require deep knowledge of a programming language: you can just describe to the neural network what you need, and within a few minutes — depending on how complex the task is — get a working result.

This isn't speculation or a hypothesis — it's happening right now, every day, in real development work. And it's changing the essence of the profession itself. A developer's value used to lie in being able to write code. Now, writing code is increasingly accessible without deep programming knowledge. Which means the question of "what makes a good developer" is shifting too — but more on that in the next part of the introduction.
